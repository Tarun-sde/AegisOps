# Phase Reports

Create one report per implementation phase. Phase 0 starts in `PHASE_00_FOUNDATION.md` and currently contains **only planned tasks**.

For every report include phase goal, changes, actual commands/results, screenshots/log refs when relevant, security impact, ADR/DEC IDs, outstanding risks, hosted CI confirmation, and next authorized work.

Do not call a phase complete because scaffolding exists; meet its master-plan exit gates. Use source plan §17 and §24 to name future phase reports.
