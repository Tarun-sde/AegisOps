# Architecture Decision Records

The **canonical index and the first 16 design-only architectural decisions** already live in [`../ENGINEERING_DECISIONS.md`](../ENGINEERING_DECISIONS.md).

Create separate `ADR-017-*.md` files here only for new major decisions or expanded research, and link each from the canonical journal. Do not duplicate existing ADR text unless you intentionally migrate the canonical index with traceable links.

- Record context, constraints, considered alternatives, selected approach, why alternatives lost, downside, revisit trigger, implementation status and proof.
- Never silently overwrite or delete previous rationale. Supersede it with an explicit new decision.
- Make sure every new major ADR also has a human-readable interview defense answer.
